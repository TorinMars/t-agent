# The page: dialogs, sheets and notices

> Part of the T-Agent design document. The index of all parts is [DESIGN.md](../../DESIGN.md).

## One dialog pattern

Every dialog of the page speaks one Material Design 2 language, on a computer and on a phone. The look is set once in `scripts/h5-shell/theme.mjs` (the `DIALOGS` block: `MuiDialog`, `MuiDialogTitle`, `MuiDialogContentText`), so a dialog in any file gets it; what the theme cannot decide (the kinds and order of the buttons, the width, full screen) is set where each dialog is drawn, by the rules below.

- **Title**: `DialogTitle`, MUI's `h6` (20px, medium), 24px at the sides. No hand-made sizes (`fontSize: 16/17` and `subtitle1` with weight 600 are gone). A dialog with a close button puts it at the end of the title row (`IconButton`, `aria-label` = `title` = "Close").
- **Content**: `DialogContent` with 24px at the sides; body text `DialogContentText` (`body1`, or `body2` for secondary lines), long words broken anywhere (the theme sets `overflowWrap: anywhere` on titles and body text). A scrolling dialog with a title row and an actions row uses `dividers`.
- **Actions**: `DialogActions` at the bottom right, 8px apart, MUI's 8px padding. Text buttons in the primary colour. The dismissive action ("Cancel", "Close") comes first, the confirming one last. A contained primary button only when the dialog is a form that creates or saves something (Create, Save). A destructive confirmation (Delete, Restart T-Agent, which closes every terminal) is a text button in the error colour. A forced update keeps the warning colour. A Delete inside an edit form sits at the start of the row (`mr: auto`).
- **Width**: `maxWidth="xs"` for confirmations, `"sm"` for forms (rename, working directory, visibility, paste, New task, the T-Attention edit view, Update). On a phone (under 600px) a centred dialog keeps 16px margins instead of MUI's 32px (theme: `paper`, `paperFullWidth`, `paperWidthXs/Sm/Md`, `paperScrollPaper`). Full screen on a phone only for long forms: New task and the T-Attention edit view. New session stays a short centred dialog.
- **Shape**: an 8px corner radius (`DIALOG_RADIUS`; a theming choice like the 8px of the buttons, MD2's default is 4px); a full-screen dialog has none. The top sheets of the design document and the file tree use the same 8px on their lower corners.
- **Keyboard**: a dialog that is a form is a `<form>` (a `Box component="form"` inside, or the paper itself through `slotProps.paper.component`), so Enter in a one-line field submits and Escape closes (MUI). The first field takes the focus (`autoFocus`). A multi-line field keeps Enter for a new line.
- **Errors**: as the field's `helperText`, or an inline MUI `Alert` under the fields (`DialogError` in `common.jsx`: `severity="error"`, `role="alert"`), never only as a notice. Ids kept: `#h5-task-dialog-error`, `#h5-new-session-error`, `#h5-restart-error`, `#h5-attention-edit-error`; new `#h5-new-task-error`.
- **Sheet headers** (the file tree, the design document and its outline drawer, T-Attention): 56px, the title in `h6` with a `caption` (or `body2`) line under it, the icon buttons at the end (`SHEET_HEADER_SX` in `Design.jsx`).

Dialogs of this part: the copy view (full screen, its own app bar), upload progress, Paste (`#h5-paste`, a form at the top of the screen, Send is a text submit button), the uploaded link (`.h5-upload-overlay`, title "Uploaded link(s)", the reason as body text), the task dialogs of `TaskDialogs.jsx` (rename, working directory, visibility: forms with Save; archive: a text confirmation; delete: a text button in the error colour), New session and New task (`page-task-list.md`), Update (`#h5-update-dialog`: Close, then Choose force update…, Check again, Update now, all text buttons; the details in `body2`, commands and the log in a monospace `caption`), Restart T-Agent (`#h5-restart-dialog`), and the T-Attention edit view, Reject and Delete (`page-attention.md`).

Dialogs of other parts get the title, padding, margins and radius from the theme. Checked at the single-view redesign: the Settings dialogs (`Form.jsx` sheets, pairing, engine rename, service links, browser extension, marketplace, rule sync) keep `color="inherit"` on Cancel and some contained confirmations, which the theme cannot change; they move to the pattern when their files are changed.

Regression: the dialog tests of each part (`test-h5-create-dialogs-browser.cjs`, `test-h5-task-rename-browser.cjs`, `test-h5-restart-browser.cjs`, `test-h5-paste-browser.cjs`, …) and `scripts/test-h5-dialog-pattern-browser.cjs` (the title variant, the order and kinds of the actions of several dialogs, Enter and Escape, the 16px margins on a phone).
