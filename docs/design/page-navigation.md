# The page: navigation rail, session header and phone drawer

> Part of the T-Agent design document. The index of all parts is [DESIGN.md](../../DESIGN.md).

The single view (one terminal, the default view) has the navigation language of the columns view since the single-view redesign (2026-11).

## Navigation rail

- `NavRail` in `Columns.jsx`, drawn by `App.jsx` (`#h5-columns-nav`, a `nav` landmark "Views"; the id is kept from the columns view, whose rail it was; the columns view itself is in [page-shell-and-columns.md](page-shell-and-columns.md)): one rail for both views, on the wide layout only, fixed at the left edge, 72px (`NAV_WIDTH`), the whole height, z-index 1260 (above the columns view at 1250 and the full-window mind map, below MUI dialogs and menus at 1300). MD2 navigation rail on the paper colour with the 1dp overlay and a 1px divider. Destinations (`RAIL_DESTINATIONS` / `railDestinations` in `columns.mjs`; `.h5-nav-item`, 72 x 56px, a 24px icon over a caption label): Sessions (`#h5-nav-sessions`, library `code`: the single view; in the columns view it leaves the view), Columns (`#h5-nav-columns`, enters the columns view on its Columns tab, red badge `#h5-nav-needs` of the open columns that need the person, only while the view is shown), Attention (`#h5-nav-attention`, toggles the T-Attention panel on the right, `aria-expanded` and a primary tint while it is open, red badge `#h5-nav-attention-count` with `state.attention.needs`, the count of the bottom area's `#h5-attention`; label "Attention, 1 item needs you" / "Attention, N items need you"), Mind maps (`#h5-nav-maps`, the Mind maps tab of the columns view, entering the view when it is off). At the bottom: Update (the page's one updater, `UpdateButton` with `#h5-update` and its red dot, 48px with a 22px icon) and Settings (`#h5-nav-settings`, 48px, library `setting`). The current page (`railView`: Settings while `state.settingsOpen`, else the columns view's tab while it is shown, else Sessions) is in the primary colour with a 3px indicator and `aria-current="page"`. Choosing any destination while Settings is open closes it first (`closeSettings()`); Settings itself opens with `openSettings()`. Each destination (Settings included, Update not) is a Tab stop; Up / Down / Left / Right move between them, wrapping, Home / End go to the first / last (`railKey`); a focus ring on keyboard focus. `ui.actions.showView('sessions' | 'columns' | 'maps')` (Columns.jsx `startColumns`) does the switching. A page that cannot show the columns view (a framed page, a top-level `?pane=`: `state.columns` is null) has no Columns destination and its Mind maps opens the full-window mind map (`openMindmaps`), which starts right of the rail there. The rail stays mounted on a narrow screen with `display: none` (so the updater inside it keeps its one poll across a resize; the phone opens its dialog through `ui.actions.openUpdate`); a pane has no rail. While it is shown `html[data-nav-rail]` sets `--h5-nav-width: 72px`. The old header switch `#h5-columns-open`, the rail's leave switch `#h5-columns-toggle` and its second Update button `#h5-columns-update` are gone.

## Page layout

- Wide, left to right: the rail (72px), the task list (304px, foldable with `#h5-sidebar-toggle`; its paper is fixed at `left: var(--h5-nav-width)`), then `#h5-app` (header, terminal, bottom row) and the chat from `calc(var(--h5-nav-width) + var(--h5-sidebar-width))` (`public/css/h5.css`), ending where the T-Attention panel starts (`html[data-side-panel]`). `terminal-box.mjs` keeps measuring the terminal box (the rail calls `measureTerminalBox()` when it appears), so the top sheets still line up with the terminal. The columns view is `left: NAV_WIDTH` (right of the rail); the T-Attention panel is shown above it too (its paper at z-index 1255) and the view ends where the panel starts; Settings gets z-index 1255 over the view. The skeleton in `h5.html` has the rail, the 304px sidebar edge and the 48px / 56px header.

## Session header

- `Header.jsx`. Computer: a dense 48px bar (47px + the 1px line) on the paper colour with the 1dp overlay that reads like a column header: the fold toggle, then `#h5-open-tasks` (a click unfolds a folded sidebar; inert while the sidebar is shown) with the state dot of the shown session, its device tag (`#h5-task-service`), "task · session" on one line cut with an ellipsis (`#h5-task-name` subtitle1 500, `#h5-session-name` body2 secondary), then the agent and "running" as a caption, or a warning "Needs you" chip; at the right "Wide terminal" (`WidthButton`, unchanged) and "More" (`#h5-header-more`, `taskMore`, menu `#h5-header-more-menu` with "Refresh the page", `#h5-refresh`). Phone: a 56px MD2 app bar: the menu button `#h5-open-tasks` (`menu`, "Tasks", `aria-haspopup="dialog"`, `aria-expanded`), the task name (subtitle1, 16px medium, one line) over a status line (dot, device tag, session, "· running" / "· needs you"), "Wide terminal" and "More" with "Refresh the page" and "Update" (`#h5-header-update`, with a red dot, also on the More button, while an update waits; it opens the rail's updater's dialog with `ui.actions.openUpdate` and the focus comes back to More). The live state (running / needs you / idle) is the columns view's rule (`columnStatus`) on `state.shownTarget` (`useShownState` in Columns.jsx): the small parts that draw it subscribe to it as a string, so an activity push draws them only when the state changes and never the header (`scripts/test-h5-render-count-browser.cjs`).

## Phone drawer

- `TaskDrawer` in `TaskDrawer.jsx`: an MD2 modal navigation drawer from the left, min(320px, 100vw - 56px) (`--h5-drawer-width`), on the paper colour with the 1dp overlay, square corners, over a 32% black scrim (`#h5-task-backdrop`); the page under it no longer slides right with rounded corners (`body.h5-tasks-open` still marks it open and `App.jsx` still makes the page and the chat inert; back.mjs closes it as any modal). Below the list (`DrawerNav`, phone only, also in a narrow pane): a divider and labelled 48px rows with a 24px icon, `#h5-tasks-nav`: T-Attention (`#h5-tasks-attention`, with a red count; not in a pane), Mind maps (`#h5-tasks-mindmap`) and Settings (`#h5-tasks-settings`); choosing one closes the drawer first. On the wide layout the task list has no footer: those entries are in the rail. `lazy-screens.jsx` preloads the Settings chunk from `#h5-nav-settings` and the T-Attention chunk from `#h5-nav-attention` and `#h5-tasks-attention` too.
