Working directory

Root directory for md files of new tasks; created if missing. Clear it to restore the default.

Image upload

Private links valid for 24 hours are generated by default; the public address is only for buckets or domains that allow public reads. Images are limited to 10 MiB and are uploaded from your browser straight to OSS, so the bucket needs a CORS rule that allows POST from this page’s address.

Translation

Each provider’s key is stored encrypted on the client. Switching providers keeps saved keys, and they are never sent to the browser or remote engines. The selected provider is used after saving. Only input containing Chinese is translated; plain English is sent as-is. Translation runs on the client, so terminals on remote engines work too.

Voice input

How sure the service must be that a sound is speech and not noise. Closer to 1 filters more noise (try 0.2 to 0.5 in a noisy room) but can cut quiet speech. It cannot tell your voice from other people talking nearby.

The key is stored encrypted on the client. The browser never receives it: it gets a one-minute token and sends the audio straight to Alibaba Cloud Model Studio, so no audio goes through the client server. Keys are specific to a region, so choose the region the key was created in. Leave the endpoint empty to use the region’s address.

Remote service

This client can also act as an engine so other clients can reach its tasks, files and terminals. On the other client choose “Connect remote” and enter this client’s address and a pairing code. The pairing code is valid for 10 minutes and can be used once.
