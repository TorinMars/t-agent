Tunnel (frp)

        
Uses frpc to map this machine’s Client port to your frps server. The remote port is generated randomly and stays stable (it can be regenerated). This is a TCP tunnel: point your domain at the frps server’s IP, then forward to server-IP:remote-port with a reverse proxy (such as Nginx, terminating HTTPS). Make sure an authenticator is bound before exposing the Client. If frpc is missing, the page offers an “Install frpc” button; you can also install it yourself (0.52 or later) and set the environment variable T_AGENT_FRPC_BIN  to its path.

        

        

          
          
        

        

          
          Click to choose: copy a prompt for an Agent to install it, or let the Client download it directly (official release + SHA-256 check; frpc is only placed in data/bin; if GitHub is unreachable, set T_AGENT_FRP_DOWNLOAD_BASE to a mirror). If you installed it with Homebrew (brew install frpc) or manually, click “Re-detect frpc” above.

SSH reverse tunnel

          
Uses  ssh -R to bind a port on the server that points to this machine’s Client port. The server port is random and stable by default, or you can set it manually. Passwordless login is required (no password prompt); the server host key is trusted and recorded on first connect. By default it only binds the server’s 127.0.0.1, so use a reverse proxy (such as Nginx) on the server to forward to that port; ticking “Bind all interfaces” also requires sshd on the server to enable GatewayPorts yes (or  clientspecified). Make sure an authenticator is bound before exposing it.

File sync

        
File sync uses a master/slave layout. The master usually has a fixed public address and slaves (which may be on an internal network) connect to it: on the master click “Generate connection string”, copy it to the slave’s “File sync” page (set its role to “Slave” first), paste and connect. Afterwards the slave downloads and syncs the files configured on the master, changes on either side sync automatically, and the file list can only be edited on the master. Home-directory paths can be written as ~/.claude/settings.json  or  home/.claude/settings.json, and absolute paths are supported.

        

          
          
        

        

        

          
Paste the connection string generated by the master (valid for 10 minutes, single use). After connecting, this node’s sync list is replaced by the master’s and the files are downloaded; files that differ locally are backed up first.

Install dev environment (Claude Code / Codex / SSH key / rule sync / ta / PM2)

        
Copy the GitHub install script command and paste it into a terminal on the target machine (macOS / Linux). Installed tools are skipped and existing SSH keys are not overwritten. It also configures, on every start, claude / codex a sync of the repository rules/ ’s user-level rules and default config (--skip sync  can be skipped); it also installs the unified command ta and PM2 (when Node.js is missing it is installed to ~/.local/node, --skip pm2  can be skipped); add bash -s -- --check to only check without installing, add --with-apps to also install Maccy, Snipaste and Clash Verge on a Mac.

        

          
          
          
        

      

      

        
Configure proxy (subscription)

        
macOS: imports the subscription into an installed Clash Verge; Linux: installs the mihomo core and runs it as a user service. After running, paste the subscription link when prompted (input is hidden and never printed or logged); afterwards use bash -s -- --update to update the subscription and--status to check the status.

        

          
          
        

      

      

        
Local install wizard (web UI)

        
Use this when you do not want to remember command-line flags: running it on the target machine starts a web wizard that only listens locally, where you tick what to install, enter the subscription link and watch live output. Requires Python 3; on a remote server, use SSH port forwarding as prompted (ssh -L 8765:127.0.0.1:8765) and open it from your local browser.
