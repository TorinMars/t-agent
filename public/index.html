Agent 配置

        
为 Claude Code 和 Codex 设置通用默认值，一次推送到本机和所有已连接的服务器。每台服务器可以单独覆盖；没填的项保持该机器上的原值，不会被改动。推送需要对方 Engine 升级到支持“Agent 配置”的版本。

内网穿透（frp）

        
用 frpc 把这台机器上的 Client 端口映射到你的 frps 服务器。远程端口自动随机生成并保持稳定（可重新生成）；这是 TCP 隧道，域名需要自己解析到 frps 服务器的 IP，再用反向代理（如 Nginx，终结 HTTPS）转发到 服务器IP:远程端口。对外暴露 Client 前请确认已绑定身份验证器。本机没有 frpc 时页面会提供“安装 frpc”按钮；也可自行安装（0.52 及以上）并用环境变量 T_AGENT_FRPC_BIN 指定路径。

        

        

          
          
        

        

          
          点击后可选择：复制提示词让 Agent 安装，或由 Client 直接下载（官方发布包 + SHA-256 校验，只把 frpc 放到 data/bin；无法访问 GitHub 时设置 T_AGENT_FRP_DOWNLOAD_BASE 指向镜像）。已用 Homebrew（brew install frpc）或手动装好时，点上面的“重新检测 frpc”。
        

        

          
          
          
          
          
          
          
          
          
          
          
          

          

          
          
          

            
            
            
            
          

        

      

      

        
安装 frps（公网服务器）

        
frps 要装在有公网 IP 的服务器上。复制下面的提示词，粘贴给能操作那台服务器的 Agent（例如在服务器上运行的 Claude Code / Codex）。提示词会带上上面填的服务端口、Token（没填则让 Agent 随机生成并告诉你）和允许的远程端口范围；提示词含 Token，请只发给你信任的 Agent。

SSH 反向隧道

          
用 ssh -R 在服务器上绑定一个端口，指向本机 Client 的端口。服务器端口默认自动随机并保持稳定，也可手动填写。必须能免密登录（不会弹出密码输入）；首次连接会自动信任并记录服务器主机密钥。默认只绑定服务器的 127.0.0.1，请在服务器上用反向代理（如 Nginx）转发到该端口；勾选“绑定所有网卡”还需要服务器 sshd 开启 GatewayPorts yes（或 clientspecified）。对外暴露前请确认已绑定身份验证器。

文件同步

        
文件同步是主从结构。主服务器通常有固定的外网地址，从服务器（可以在内网）主动去连接它：在主服务器点“生成连接字符串”，把字符串复制到从服务器的“文件同步”页（先把角色设为“从服务器”）粘贴并连接即可。连接后从服务器下载并同步主服务器配置的文件，两侧修改会自动同步，文件清单只能在主服务器修改。用户目录路径可写为 ~/.claude/settings.json 或 用户目录/.claude/settings.json，也支持绝对路径。

        

          
          
        

        

        

          
粘贴主服务器生成的连接字符串（10 分钟内有效、只能使用一次）。连接后，本节点现有的同步清单由主服务器的清单替换，并下载文件内容；与本地不同的文件会先备份。

安装开发环境（Claude Code / Codex / SSH 密钥 / 规则同步 / ta / PM2）

        
复制 GitHub 安装脚本命令，在目标机器的终端中粘贴执行（macOS / Linux）。已安装的工具会跳过，已有 SSH 密钥不会被覆盖；还会配置每次启动 claude / codex 前同步仓库 rules/ 里的用户级规则和默认配置（--skip sync 可跳过）；还会安装统一命令 ta 和 PM2（没有 Node.js 时先装到 ~/.local/node，--skip pm2 可跳过）；加 bash -s -- --check 可只检查不安装，加 --with-apps 可在 Mac 上同时安装 Maccy、Snipaste、Clash Verge。

        

          
          
          
        

      

      

        
配置代理（订阅）

        
macOS：把订阅导入已安装的 Clash Verge；Linux：安装 mihomo 内核并以用户级服务运行。运行后按提示粘贴订阅链接（输入时不显示，不会被打印或写入日志）；之后用 bash -s -- --update 更新订阅，--status 查看状态。

        

          
          
        

      

      

        
本地安装向导（网页操作）

        
不想记命令行参数时使用：在目标机器上运行后会启动一个只监听本机的网页向导，勾选要安装的内容、在页面里填写订阅链接并查看实时输出。需要 Python 3；在远程服务器上运行时，按提示用 SSH 端口转发（ssh -L 8765:127.0.0.1:8765）再从本机浏览器打开。
